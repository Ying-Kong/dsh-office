## dsh-office 0.1.0

First usable cut: **extract → fill → verify**, Word (`.docx`) only.

### What you can do

- Point it at a form a human authored, get a fact table: run-merged paragraph
  text, resolved font size and fonts (direct run → character style → paragraph
  style → base → docDefaults), stable paragraph/table/cell ids, and detected
  fill slots (empty cell right of a label, `日期：__年__月__日` lines, `___`).
- Write an `ops.json` — data, not code — and replay it:
  `set_text`, `replace_in_paragraph`, `set_format`, `append_content`
  (paragraph / heading / figure).
- Figures get a running `图 {n}` caption, are width-capped, and the caption stays
  attached to the image. Placeholder blank paragraphs are trimmed so content
  does not start below a gap.
- Verify the result: every op re-checked, plus font whitelist, sequential caption
  numbering, leftover `{{placeholders}}`, image width. Findings split into
  **hard** (must fix) and **soft** (report only).
- Template fingerprint guard: ops authored for a different build are refused
  unless `--force`.

### DSH

`@dsh-office/plugin` registers three tools — `office_extract`, `office_fill`,
`office_verify` — around a dependency-free CLI wrapper. The Python core stays
usable headless (any agent, any script).

### Quality

- 25 Python tests, 10 Node tests.
- CI: python 3.10/3.12 × Ubuntu/Windows, node 20/22/24, plus a render job that
  produces the reference report as an artifact.
- Determinism checked by content fingerprint (`document.xml`, `styles.xml`,
  `numbering.xml`, `media/*`) — whole-package bytes are not stable, by design.

### Fixtures

Anonymised course report form (`张三` / `2023000000001` / `李老师`) with
unwatermarked full-size screenshots, including a 2524×1136 frame that exercises
the width cap. `tools/sanitize_fixture.py` redacts a contributed form without
collapsing run formatting.

### Known limitations

Pagination is not asserted (engine-dependent); theme fonts and document grids
resolve to `null`; legacy `.doc` is rejected; Excel is scaffolded, PowerPoint is
a non-goal. Details in `docs/limitations.md`.
